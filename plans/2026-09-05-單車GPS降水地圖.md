# 單車 GPS 即時降水地圖（Tesla 車機雨雲圖的單車版）

> 建立時間：2026-09-05 21:44
> 類型：新功能（獨立小專案）
> 狀態：待執行

---

## 你要做的事（一句話版）

做一個部署在 GitHub Pages 的手機網頁，騎車時打開放在手機架上：藍點跟著你的 GPS 移動，
地圖疊上日本氣象庁（JMA）官方雷達回波圖，時間軸可以往前拉到未來 2 小時，
還會用你的行進方向＋速度推算「你到時會在哪」畫一個幽靈點，直接看那個未來位置會不會下雨。

## 背景和動機

11/13–12/1 東京／富士／伊豆 19 天單車行，秋末天氣多變。騎在路上時最想知道的是
「這片雨帶會不會掃到我」「我再騎 1 小時會不會進到雨區」。Tesla 車機導航內建這種
即時＋未來降水圖，單車沒有，所以自己做一個。

`riding.braintaiwan.com` 上那個 `radar-map.html` 是行前規劃用的（RainViewer、全球資料、
精度到 zoom 7、常常沒有 nowcast）。這個工具不一樣：騎乘中即時使用、日本境內、要 GPS 定位、
要真的能看到未來 2 小時，所以獨立做、換 JMA 官方資料源。

## 技術驗證（已完成，寫計劃前先確認過）

- `hrpns`（高解像度降水ナウキャスト）：`nowc/targetTimes_N1.json`（觀測，過去 60 分、5 分一格）
  ＋ `nowc/targetTimes_N2.json`（預報，未來 60 分、5 分一格），250m 網格。三個 API 都回 200 image/png。
- `rasrf`（降水短時間予報）：`rasrf/targetTimes.json`（未來 1–15 小時、每小時一格），1km 網格。回 200。
- 圖磚 URL 格式：
  - `https://www.jma.go.jp/bosai/jmatile/data/nowc/{basetime}/none/{validtime}/surf/hrpns/{z}/{x}/{y}.png`
  - `https://www.jma.go.jp/bosai/jmatile/data/rasrf/{basetime}/none/{validtime}/surf/rasrf/{z}/{x}/{y}.png`
- 圖磚用 Leaflet 的 `<img>` tile layer 載入，**不需要 CORS**（實測 JMA 沒有回 Access-Control 標頭，但 `<img>` 不受限）。
- 放大到 z10 以上仍有圖磚（不像 RainViewer 卡在 z7）。
- ⚠️ 這是 JMA 官方網站自己在用、但**沒有公開文件**的端點（跟 NAVITIME 逆向同性質）。哪天格式變了要跟著修。

## 具體步驟

### Step 1：專案骨架
- 做什麼：在 `D:\biking gps weather` 建立 `index.html`（單一檔、無 build step）、
  `manifest.webmanifest`（讓手機可「加到主畫面」）、`README.md`、`.gitignore`。
- 產出：可本機用 `python -m http.server` 開起來的空殼，Leaflet + OSM 底圖會顯示。
- 注意：Leaflet 用跟 `radar-map.html` 一樣的 `unpkg.com/leaflet@1.9.4`，版本對齊。

### Step 2：GPS 即時定位（藍點）
- 做什麼：`navigator.geolocation.watchPosition()` 持續追蹤，畫使用者位置藍點＋精度圈，
  地圖中心跟隨（可用一個「鎖定/解鎖跟隨」按鈕，讓使用者能自己平移看別處後再回中心）。
  顯示目前速度（km/h）與方向。
- 產出：手機上（HTTPS）開啟後，藍點跟著人移動。
- 注意：`file://` 定位會被瀏覽器擋，本機測試要用 `http://localhost`；真正使用一定要 HTTPS（GitHub Pages）。
  取不到定位時要有明確提示（權限被拒 / 室內收不到訊號）。

### Step 3：JMA 雷達圖層 ＋ 時間軸
- 做什麼：
  1. 載入時抓 `nowc/targetTimes_N1.json`、`nowc/targetTimes_N2.json`、`rasrf/targetTimes.json`。
  2. 組成一條時間軸：過去 60 分（hrpns 觀測）→ 現在 → 未來 60 分（hrpns 預報，5 分一格）
     → 未來 90 分、120 分（rasrf，每小時一格，取 +2h 內的格）。
  3. 一個 Leaflet tile layer，隨時間軸 index 換 URL；`opacity` 約 0.6、`maxNativeZoom` 視 JMA 上限設定。
  4. 時間軸 UI：滑桿 ＋ 播放/暫停 ＋ 目前顯示時刻標籤（JST，並標「觀測 / 預報」）。
  5. 每 2–3 分鐘自動重抓 targetTimes（JMA 每 5 分更新一次），無痛換新資料。
- 產出：可以拉時間軸看雨帶從過去到未來 2 小時的移動，會自動更新。
- 注意：hrpns 和 rasrf 是兩個不同 element、不同 basetime，換圖層時 URL 要各自組。
  兩段解析度不同（250m vs 1km），交界處畫面粗細會變，UI 上標清楚「此格為短時間予報（較粗）」。

### Step 4：「推算位置」幽靈點
- 做什麼：時間軸往前拉 N 分鐘時，除了換雷達圖，也用目前 GPS 的
  `heading`（行進方向）＋ `speed`（速度）做等速直線外推，在地圖上畫一個半透明幽靈點，
  代表「若維持現在方向與速度，你 N 分鐘後大概在這」。幽靈點旁標「+N 分 · 約 X km 後」。
- 產出：滑桿拉到 +90 分，幽靈點跳到前方對應距離，一眼看那裡的雷達回波顏色。
- 注意：只做等速直線外推（YAGNI，不接路線規劃、不轉彎）。`speed` 為 0 或 null（靜止/剛開）時，
  幽靈點就疊在現在位置上，並標「靜止中，無法推算前方位置」。方向抖動時做輕度平滑。

### Step 5：騎乘體驗細節
- 做什麼：
  - JMA 標準降水強度色階圖例（淡藍 1mm/h → 深紫 80mm/h+）。
  - Screen Wake Lock API 防止螢幕自動關（附開關，預設開）。
  - 大按鈕、高對比、資訊列固定在下緣（騎乘中好按好看）。
  - 深色底圖選項（傍晚騎乘）。
  - 「目前位置雨況」一行摘要：讀現在這格雷達在你座標的回波值，直接寫「你頭上目前：無雨／小雨…」。
- 產出：實際騎乘可用的介面。
- 注意：Wake Lock 在部分瀏覽器要 HTTPS＋使用者互動後才給，失敗不報錯只是不鎖。

### Step 6：部署到 GitHub Pages
- 做什麼：
  1. `D:\biking gps weather` `git init`，建立新 GitHub repo `ymeroom/biking-gps-weather`。
  2. push 後開 Settings → Pages → 從 `main` 分支根目錄發佈。
  3. 手機開 `https://ymeroom.github.io/biking-gps-weather/`，允許定位，加到主畫面，實地測一次。
- 產出：手機主畫面一個 icon，點開就是這個工具。
- 注意：第一次 push 前確認沒有把測試截圖、`.remember/` 等雜物加進 commit。

## 預計成果

做完以後你會得到：
- 手機瀏覽器開一個網址（可加到主畫面像 App），藍點跟著你騎。
- JMA 官方雷達回波圖疊在地圖上，時間軸可看「過去 1 小時 → 現在 → 未來 2 小時」。
- 一個幽靈點顯示「照現在方向速度，N 分鐘後你大概在這」，直接對照那裡的雨況。
- 螢幕不會自己關、色階看得懂、傍晚有深色模式。
- 原始碼在 `D:\biking gps weather`，之後要改隨時能改、重新 push 就更新。

## 不包含在這次的範圍

- 日本以外的雷達資料（這工具就是為日本騎行做的）。
- 路線規劃、沿實際路線（會轉彎）推算未來位置 —— v1 只做等速直線外推。
- 離線快取雷達圖磚（沒訊號時只顯示「離線」）。
- 航跡記錄、匯出 GPX、歷史回放。
- 降雨語音／震動警報。
- 跟 `riding.braintaiwan.com` 或 `trip.json` 的任何整合（完全獨立）。

## 可能遇到的風險

- **JMA 端點無預警改格式**：非公開 API。處理：URL 組法集中在一個函式、targetTimes 解析失敗時
  顯示明確錯誤（「JMA 資料格式可能變了」）而不是靜默空白。
- **手機定位在市區高樓/隧道飄移或中斷**：處理：顯示定位精度、訊號中斷時凍結最後位置並標「訊號中斷 Xs」。
- **`heading`/`speed` 欄位部分裝置不給**：處理：偵測到 null 就降級——不畫幽靈點，只保留時間軸功能。
- **GitHub Pages 上 JMA 圖磚被 mixed-content 或 referrer 政策擋**：處理：部署後第一件事就是實機驗證圖磚有載入；
  必要時加 `referrerpolicy="no-referrer"` 到 tile。
- **騎乘中耗電**：GPS＋螢幕常亮很吃電。處理：README 提醒帶行動電源；Wake Lock 可關。
